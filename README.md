# MM2 Auto-Farm Script

This script adds an Auto-Farm feature to the MM2 tab in Roblox Studio. The feature includes an on/off toggle for Auto-Farm and a speed setting (1-27) for Auto-Farm. The script allows players to automatically collect coins in the MM2 game, even when the round ends or when the player reaches the maximum coins.

## Installation

1. Open Roblox Studio and load your game.
2. Navigate to the StarterGui or PlayerGui in the Explorer.
3. Create a new Script and name it "MM2AutoFarm".
4. Copy and paste the contents of the MM2AutoFarm.lua file into the script.
5. Save the script.

## Usage

- Toggle the Auto-Farm feature on/off using the button in the MM2 tab.
- Adjust the Auto-Farm speed using the slider in the MM2 tab.

## Notes

- The script will stop when the round ends or when the player reaches the maximum coins.
- The Auto-Farm Speed setting allows the player to collect coins even inside walls.
